# Repackshot 0.1.24

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release.** Its new features:

- **two more API presets**: Google Gemini and xAI Grok Imagine, for the AI post-processing through a remote API;
- **Test connection**: one real call that says whether the configured API answers;
- **stopping a render saves the image so far**, as `<name>-partial`, instead of throwing it away;
- **fixed**: the AI switch that only ever opened Settings, and the render shortcuts that fired while typing.

## What's new

### Two more API presets

- **Google · Gemini image** (`gemini-2.5-flash-image`): the key goes in the `x-goog-api-key` header with nothing before it, the prompt carries the negative as *Avoid: …*, the seed goes in `generationConfig`, and the answer is read at `candidates.0.content.parts.1.inlineData.data`.
- **xAI · Grok Imagine** (`grok-imagine-image-2.0`): `Authorization: Bearer`, the image as a data URI, and the answer at `data.0.b64_json`.
- Both are written from the services' public API documentation and have not been tried against the live services yet. Services that need polling, or that answer with a link instead of an image, are still not presets — the single-call endpoint cannot do them.

### Test connection

- **Test connection** (Settings ▸ AI ▸ Model by API): one minimal call through the endpoint as configured — a 512 × 512 solid grey tile, *Return this image unchanged.* — reporting whether the service answered with an image, or the call's error in words. On desktop it runs through the launcher (`POST /api/ai/ping`) with the stored key; on the web through the same code path as a render's call. Clicking it is the consent for that one call. The probe is 512 × 512, not smaller, so an answer at the service's native 1024 × 1024 still passes the size guard.

### Stopping a render saves the image so far

- **Pausing the queue, or *Stop* on the job being rendered, keeps the accumulation** up to where the render had reached: saved apart as `<name>-partial` (a video's stopped frame as a PNG) and kept in the results history, marked *Partial*, with the samples it reached.
- The stopped job still starts over on *Resume*: a render is not resumed halfway, but the work it had done is no longer thrown away.
- A stop that lands mid-pass is read back at the last completed pass's sample count, so no tile comes out too bright. A partial carries only its main image — no noisy companion, no pass files.

### Fixed

- **Fixed: `{{image_base64}}` (and `{{depth_base64}}`, `{{edges_base64}}`) never filled.** The placeholder pattern allowed only letters and underscores, no digits, so a template using `{{image_base64}}` validated as *no image* and the render window's AI switch only ever opened Settings, never turned on. The pattern now takes digits too, on the page and in the launcher.
- **Fixed: the queue no longer starts from a `Ctrl/⌘ ⏎` pressed while typing.** The Render shortcuts were global, so they fired even inside a text field — typing a prompt and pressing the usual confirm gesture started a render without the Render button ever being pressed. Render and Render now are no longer global: they still work with the focus outside a field.

The full list, with its limitations, is in `docs/CHANGELOG.md`. The screenshots, by version and by feature, are in [`docs/GALERIA.md`](https://github.com/Grohle-developer/Repackshot/blob/v0.1.24/docs/GALERIA.md).

## Downloads

- **Repackshot-0.1.24-windows-x64-portable.zip**: Windows portable. Unzip it and run `repackshot.exe`. Data stays in the `data` folder next to the program.
- **Repackshot-0.1.24-windows-x64-setup.exe**: Windows installer, for your user only and without administrator. Data goes to `%LOCALAPPDATA%\Repackshot`.
- **Repackshot-0.1.24-linux-x64-portable.tar.gz**: Linux portable; it needs Chromium, Chrome, Edge or Brave (and glibc 2.38 or later for the AI).
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages. On Linux: `sha256sum -c SHA256SUMS.txt`; in PowerShell: `Get-FileHash .\Repackshot-0.1.24-windows-x64-setup.exe -Algorithm SHA256`.

The film simulation plugin does not change: it is still `film-0.1.0.rpk`, the asset of the 0.1.6 release.

The `.exe` is not signed: SmartScreen may stop the first start (**More info**, then **Run anyway**).

## Known limitations

- **AI through an API.**
  - None of the four presets has been tried against its live service yet.
  - Only PNG answers are read, and an answer given as a link is not followed.
  - In the browser, a service that does not allow cross-origin requests fails as a network error, and the guard runs on the page's own thread.
  - Plain `http` is only allowed to this computer; a service elsewhere on the network needs `https`.
- Those of 0.1.23 remain.

For testers: a manual Windows test plan is in [docs/testing/windows-checklist.md](https://github.com/Grohle-developer/Repackshot/blob/main/docs/testing/windows-checklist.md).
