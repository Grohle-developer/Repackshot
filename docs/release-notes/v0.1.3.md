# Repackshot 0.1.3

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release, and it fixes one thing.** When 0.1.2 was tested on Windows, no graphics card was detected on any machine, only the processor. Everything else is as in 0.1.2.

## What was fixed

- **Graphics cards are visible on Windows.** The bug was in how the Windows registry was read: `reg` ends with an error when it reaches a protected key, and Repackshot then threw away everything it had read. Now it asks DXGI (with the exact video memory), the registry key by key, `Win32_VideoController` and `wmic`, and keeps whatever answers. If none answers, *Settings* says “The graphics cards could not be read: see the logs” instead of saying there are none. The choice between Vulkan and CPU for the AI engine, and the model recommendation, depend on this.
- **The log says what happened.** The lines starting with `hardware:` in `logs\repackshot.log` tell what each source answered.
- Internal, no visible effect: exact engine passes for AI post-processing (which still does not generate images).

The full list is in `docs/CHANGELOG.md`.

## Downloads

- **Repackshot-0.1.3-windows-x64-portable.zip**: Windows portable. Unzip it and run `repackshot.exe`. Data stays in the `data` folder next to the program.
- **Repackshot-0.1.3-windows-x64-setup.exe**: Windows installer, for your user only and without administrator. Data goes to `%LOCALAPPDATA%\Repackshot`.
- **Repackshot-0.1.3-linux-x64-portable.tar.gz**: Linux portable; it needs Chromium, Chrome, Edge or Brave.
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages. On Linux: `sha256sum -c SHA256SUMS.txt`; in PowerShell: `Get-FileHash .\Repackshot-0.1.3-windows-x64-setup.exe -Algorithm SHA256`.

The `.exe` is not signed: SmartScreen may stop the first start (**More info**, then **Run anyway**). The requirements and limitations are those of 0.1.2; AI post-processing still does not generate images.

For testers: a manual Windows test plan is in [docs/testing/windows-checklist.md](https://github.com/Grohle-developer/Repackshot/blob/main/docs/testing/windows-checklist.md).
