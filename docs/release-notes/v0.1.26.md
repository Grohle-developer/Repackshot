# Repackshot 0.1.26

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release.** Its new features:

- a **window asks about a newer version** as the application opens, instead of only a line of the status bar.

## What's new

### A window asks about the update at startup

- The startup check already looked for a newer version, but only said so in a line of the status bar, easy to miss. Now a window asks as the application opens: it names the version and when it was published, with *Install and restart* on the desktop (or *Download* where the application cannot install itself), *Release notes* and *Later*.
- It is asked once per version and session. Answering the window leaves the offer as the status-bar line, which stays until its own *Later*.
- Checking by hand (*Settings ▸ Updates ▸ Check for updates*) does not open the window: it keeps reporting in the status bar, as before.

The full list, with its limitations, is in `docs/CHANGELOG.md`. The screenshots, by version and by feature, are in [`docs/GALERIA.md`](https://github.com/Grohle-developer/Repackshot/blob/v0.1.26/docs/GALERIA.md).

## Downloads

- **Repackshot-0.1.26-windows-x64-portable.zip**: Windows portable. Unzip it and run `repackshot.exe`. Data stays in the `data` folder next to the program.
- **Repackshot-0.1.26-windows-x64-setup.exe**: Windows installer, for your user only and without administrator. Data goes to `%LOCALAPPDATA%\\Repackshot`.
- **Repackshot-0.1.26-linux-x64-portable.tar.gz**: Linux portable; it needs Chromium, Chrome, Edge or Brave (and glibc 2.38 or later for the AI).
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages. On Linux: `sha256sum -c SHA256SUMS.txt`; in PowerShell: `Get-FileHash .\Repackshot-0.1.26-windows-x64-setup.exe -Algorithm SHA256`.

The film simulation plugin does not change: it is still `film-0.1.0.rpk`, the asset of the 0.1.6 release.

The `.exe` is not signed: SmartScreen may stop the first start (**More info**, then **Run anyway**).
