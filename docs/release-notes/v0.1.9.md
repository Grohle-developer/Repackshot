# Repackshot 0.1.9

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release** with a new feature requested in the bug report of 2026-10-14: **watching the selected render live in the queue**.

## What's new

- **Live view in the queue.** In the render window’s queue, click (or press Enter on) the row of the job being rendered: its image opens over the viewport and cleans up as it is made, with the *Live* label, the file name and the engine’s numbers (size, samples done out of those requested, time and camera). When the job finishes, the view moves to its result by itself. A waiting job says it has not started yet and shows its image as soon as the queue reaches it; a finished one opens the results viewer as usual. *Close* or Esc removes it.
- It does not slow the render down: the image is made at most twice a second and only while you are watching it. Measured with the same job, view open against closed, the difference falls within the noise, both in the browser and on the desktop.

The full list, with its limitations, is in `docs/CHANGELOG.md`.

## Downloads

- **Repackshot-0.1.9-windows-x64-portable.zip**: Windows portable. Unzip it and run `repackshot.exe`. Data stays in the `data` folder next to the program.
- **Repackshot-0.1.9-windows-x64-setup.exe**: Windows installer, for your user only and without administrator. Data goes to `%LOCALAPPDATA%\Repackshot`.
- **Repackshot-0.1.9-linux-x64-portable.tar.gz**: Linux portable; it needs Chromium, Chrome, Edge or Brave (and glibc 2.38 or later for the AI).
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages. On Linux: `sha256sum -c SHA256SUMS.txt`; in PowerShell: `Get-FileHash .\Repackshot-0.1.9-windows-x64-setup.exe -Algorithm SHA256`.

The film simulation plugin does not change: it is still `film-0.1.0.rpk`, the asset of the 0.1.6 release.

The `.exe` is not signed: SmartScreen may stop the first start (**More info**, then **Run anyway**).
## Known limitations

- On the desktop the live image changes once per engine pass (1, 2, 4, 8, 16 samples…), not every half second.
- There is no zoom or 100 % view while the job is running; the thumbnail of the running row is still the icon.
- Those of 0.1.8 and 0.1.7 remain.

For testers: a manual Windows test plan is in [docs/testing/windows-checklist.md](https://github.com/Grohle-developer/Repackshot/blob/main/docs/testing/windows-checklist.md).
