# Repackshot 0.1.12

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release** with a feature the bug report of 2026-10-14 asked for: **node materials work in *Full* mode and in renders**, not only in *Fast*.

## What's new

- **Nodes in the engine.** A material made in the *Material editor* (*Nodes…*) is painted in *Full* and in the render point by point, with the same numbers as in *Fast*: noises, ramps, mixes, checks, stripes, images with their mapping, Fresnel, edge curvature, normal and relief maps. Any output of the graph (colour, roughness, metal, clear coat, transmission, emission, opacity, normal…) reaches the real material.
- Of the editor’s ten examples (plastic with a label, brushed metal, marble, leather, wood, dirty glass, checks, metallic paint, glazed ceramic, stripes), seven match *Fast* in place and tone; brushed metal and dirty glass are similar in tone (their pattern is in the relief and the transmission, which *Fast* approximates).
- The inspector and editor notes no longer say *coming soon*.
- A scene without node materials renders as before, pixel for pixel.

The full list, with its limitations, is in `docs/CHANGELOG.md`.

## Downloads

- **Repackshot-0.1.12-windows-x64-portable.zip**: Windows portable. Unzip it and run `repackshot.exe`. Data stays in the `data` folder next to the program.
- **Repackshot-0.1.12-windows-x64-setup.exe**: Windows installer, for your user only and without administrator. Data goes to `%LOCALAPPDATA%\Repackshot`.
- **Repackshot-0.1.12-linux-x64-portable.tar.gz**: Linux portable; it needs Chromium, Chrome, Edge or Brave (and glibc 2.38 or later for the AI).
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages. On Linux: `sha256sum -c SHA256SUMS.txt`; in PowerShell: `Get-FileHash .\Repackshot-0.1.12-windows-x64-setup.exe -Algorithm SHA256`.

The film simulation plugin does not change: it is still `film-0.1.0.rpk`, the asset of the 0.1.6 release.

The `.exe` is not signed: SmartScreen may stop the first start (**More info**, then **Run anyway**).
## Known limitations

- The **flakes of the example metallic paint** come out darker in *Full* than in *Fast*; how the *Normal map* node should treat inward-facing normals is still to be decided.
- The wood of the example graph does not yet resemble the catalogue’s oak; there are no *Wood* or *Fabric* nodes (switching a catalogue wood or fabric to nodes loses its pattern in *Full*).
- A node material with emission that varies across the surface lights with more noise (it is not sampled as a light); a graph’s *Internal scattering* output is not read.
- A scene with many node materials takes about 40–47 % longer.
- Those of 0.1.11 remain.

For testers: a manual Windows test plan is in [docs/testing/windows-checklist.md](https://github.com/Grohle-developer/Repackshot/blob/main/docs/testing/windows-checklist.md).
