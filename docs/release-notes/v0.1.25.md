# Repackshot 0.1.25

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release.** Its new features:

- **fixed**: opening a `.repack` file from the file manager closed the program — a project file now opens at startup;
- **Open project** in the empty state, next to *Import model*;
- **fixed**: the AI connection test showed neither success nor failure — its result now stays on screen.

## What's new

### A project file opens at startup

- The launcher takes one project file on its command line (`repackshot.exe file.repack`, or `.repack.json`). Before, any argument it did not know ended the program, and the Windows build has no console, so it died silently — which is what double-clicking a project file did once the file type was associated with Repackshot.
- The page asks the launcher for the file when it loads (`GET /api/startup-project`) and opens it, like a dropped file: the project's name in the header, its parts in the panel. The *Startup* preferences (the example, the last project) apply only when no file was passed.
- A second project file, or an unknown argument, is still refused.
- A file opened this way has no remembered place on disk, so the first *Save* asks where to put it, like a dropped file without a handle.

### Open project in the empty state

- The empty viewport offers *Open project* next to *Import model* and *Load example part*: a project can be opened from the first screen, without the menu or a drag.

### The connection test keeps its result

- **Fixed: *Test connection* showed nothing.** The result line was written when the test finished and then wiped by the panel's own refresh, which runs as the test ends — with a key stored, the refresh cleared the line, so the test seemed to say neither success nor failure. The result now stays until the endpoint's configuration changes or the key goes away, and a stale result is dropped when the configuration it describes is no longer the one on screen.

The full list, with its limitations, is in `docs/CHANGELOG.md`. The screenshots, by version and by feature, are in [`docs/GALERIA.md`](https://github.com/Grohle-developer/Repackshot/blob/v0.1.25/docs/GALERIA.md).

## Downloads

- **Repackshot-0.1.25-windows-x64-portable.zip**: Windows portable. Unzip it and run `repackshot.exe`. Data stays in the `data` folder next to the program.
- **Repackshot-0.1.25-windows-x64-setup.exe**: Windows installer, for your user only and without administrator. Data goes to `%LOCALAPPDATA%\\Repackshot`.
- **Repackshot-0.1.25-linux-x64-portable.tar.gz**: Linux portable; it needs Chromium, Chrome, Edge or Brave (and glibc 2.38 or later for the AI).
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages. On Linux: `sha256sum -c SHA256SUMS.txt`; in PowerShell: `Get-FileHash .\Repackshot-0.1.25-windows-x64-setup.exe -Algorithm SHA256`.

The film simulation plugin does not change: it is still `film-0.1.0.rpk`, the asset of the 0.1.6 release.

The `.exe` is not signed: SmartScreen may stop the first start (**More info**, then **Run anyway**).
