# Repackshot 0.1.4

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release.** It finally brings **AI post-processing working end to end on the desktop**. The first real image on a graphics card is still to be produced: there is no GPU here, and it has only been tried with a fake runtime and once with SD 1.5 on CPU. It also brings our own physical sky, primitives and the scale tool.

## What's new

- **AI post-processing, end to end (desktop only).** In the render window, the *AI post-processing* switch no longer says *coming soon*. A final render with the AI on is done in the launcher: stable-diffusion.cpp with the active model, tile by tile, a deterministic guard that checks that shapes, material colour and focus do not move, and retries with less intervention if something does not pass. The history stores both images (`…_0001.png` and `…_0001_AI.png`) and the report, and the viewer compares them with the *Render | AI* divider. The queue says which step it is on (*AI · loading the model*, *AI · tile 2 of 4*). With Intervention 0 the runtime is not even started and the image is the engine’s, byte for byte.
- **Own physical sky.** *Environment ▸ Sky* gains *Model*: *Physical* (the default), with coefficients fitted by us to our own simulation of the atmosphere, or *Classic*, the previous one. Old projects open with the physical one.
- **Primitives.** *Add ▸ Primitive*: box, plane, disc, cylinder, pedestal, sphere, cone, torus, capsule, tube, steps and infinity sweep. The box and the pedestal are born as a base under the product, and the infinity sweep fits the camera. Their dimensions, in mm, are edited live in the *Primitive* section of the inspector.
- **Scale tool.** `S` in the view bar, and *right click ▸ Scale…* on a part in the viewport or the tree, with uniform scale, per axis or custom in mm.
- On Windows, if the runtime lacks the Visual C++ environment, *Settings* says so and a button opens Microsoft’s page.

The full list is in `docs/CHANGELOG.md`.

## Downloads

- **Repackshot-0.1.4-windows-x64-portable.zip**: Windows portable. Unzip it and run `repackshot.exe`. Data stays in the `data` folder next to the program.
- **Repackshot-0.1.4-windows-x64-setup.exe**: Windows installer, for your user only and without administrator. Data goes to `%LOCALAPPDATA%\Repackshot`.
- **Repackshot-0.1.4-linux-x64-portable.tar.gz**: Linux portable; it needs Chromium, Chrome, Edge or Brave (and glibc 2.38 or later for the AI).
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages. On Linux: `sha256sum -c SHA256SUMS.txt`; in PowerShell: `Get-FileHash .\Repackshot-0.1.4-windows-x64-setup.exe -Algorithm SHA256`.

The `.exe` is not signed: SmartScreen may stop the first start (**More info**, then **Run anyway**).

## Known limitations

- **The first real AI image on a graphics card has not been tested.** The timings, and the guard’s tolerances, are provisional until they are measured on a machine with a GPU.
- On Windows the runtime needs the **Microsoft Visual C++ 2015–2022 (x64)** environment, which does not ship with Repackshot; the button in *Settings* opens Microsoft’s page.
- **The web version still has no AI**, and animations do not go through the AI either.
- Only SD 1.5 carries ControlNet; with the other models the guard is what protects the shapes.
- **Physical sky with a low sun** (under about 10° of elevation): it departs from the physics by 5 to 17 %, which shows at dawn and in the golden hour with haze.
- Moving the camera does not refit the infinity sweep by itself (use *Fit to camera*).
- The limitations of earlier versions remain, above all that the new desktop features **have not been tested on a real Windows machine**.

For testers: a manual Windows test plan is in [docs/testing/windows-checklist.md](https://github.com/Grohle-developer/Repackshot/blob/main/docs/testing/windows-checklist.md).
