# Repackshot 0.1.1

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

This release adds **Check for updates**: a new *Updates* section in Settings, above *About*, and a background check when the app starts. When a newer version is published, a line in the status bar offers *Download*, *Release notes* and *Later*; nothing opens by itself. While the repository is private, the check says that no published releases were found.

Everything else is as in 0.1.0. It is alpha software: expect rough edges, and read the known limitations below.

## Downloads

There are three packages. Each one is for a different use.

- **Repackshot-0.1.1-windows-x64-portable.zip** is the portable version for Windows. Unzip it into any folder and run `repackshot.exe`. Your settings, AI models and logs stay in the `data` folder next to the program.
- **Repackshot-0.1.1-linux-x64-portable.tar.gz** is the portable version for Linux. Untar it and run `./repackshot`. It needs a Chromium-family browser installed. The program itself is static and runs on any distribution.
- **Repackshot-0.1.1-windows-x64-setup.exe** is the Windows installer. It installs for your user only, so no administrator rights are needed, into `%LOCALAPPDATA%\Programs\Repackshot`. During setup you choose which AI models the app downloads on its first start. You can choose none.

Close the Repackshot window to quit.

## Requirements

- **Windows:** Windows 10 or 11, x64, with Microsoft Edge. Edge comes with Windows. Google Chrome is used when Edge is missing.
- **Linux:** Linux on x86_64, with Chromium, Google Chrome, Microsoft Edge or Brave installed. Set `REPACKSHOT_BROWSER` to choose a different one.

## Windows warning

The Windows files are not signed with a code-signing certificate. Windows SmartScreen may stop the first start. To run the program anyway, click **More info**, then **Run anyway**.

## Known limitations

- There is no AI post-processing yet. You can download and prepare the AI models, but the post-processing step is not in this release.
- There is no video encoding. Animations render as frame sequences.
- The Windows build has been tested under Wine, not on a real Windows machine. It is not code-signed.
- For STEP and IGES files, the program assumes that Z is the up axis, because those formats do not declare one.
- There is no macOS build.

The full list of changes is in `docs/CHANGELOG.md`.

## Verify your download

Each release includes `SHA256SUMS.txt`. It lists the SHA-256 sums of the three packages.

On Linux, run this in the folder with the downloads:

```
sha256sum -c SHA256SUMS.txt
```

On Windows, run this in PowerShell and compare the result with the file's line in `SHA256SUMS.txt`:

```
Get-FileHash .\Repackshot-0.1.1-windows-x64-setup.exe -Algorithm SHA256
```
