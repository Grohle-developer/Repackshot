# Repackshot 0.1.2

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release.** It brings the desktop fixes that followed testing of 0.1.0. Most of what concerns the app's own window has only been verified under Wine so far, and it needs testing on a real Windows machine.

## What's new

- **Own window on Windows.** It is no longer a browser tab: it is a Repackshot window drawn by Edge WebView2, with the logo in the header instead of the three bars, its own icon in the taskbar and the system title bar (dark with the dark theme).
- **Closing asks through our own window.** Closing with unsaved changes (button, `Alt F4` or taskbar) shows Repackshot's *Save · Don’t save · Cancel*, never Edge's prompt.
- **No browser behaviour.** No context menu, no mini menu when selecting text, no offer to translate, no `Ctrl F`, `Ctrl P`, `Ctrl R` and no keyboard zoom.
- **System dialogs** for importing, saving a project and choosing an output folder, in front of the window. Renders, projects and models are written by the launcher, with no downloads bubble.
- **Everything is saved in the data folder.** Settings, library, results history and thumbnails **survive a restart**; before, they were lost. No row in *Settings* talks about the browser any more and texts no longer overlap. *Settings ▸ AI post-processing ▸ This computer* lists the real graphics cards.
- **Full mode no longer stalls.** A bug left the viewport frozen or at “0 samples” after a few minutes of edits. If the viewport gets stuck, it now restarts itself and the meter says why.
- **The viewport stays alive while you render**, sharing the machine (*Full · sharing with Render*). It can be changed in *Settings ▸ Render engine ▸ While a render runs*.
- **The queue pauses and resumes** (*Pause*, *Resume*, *Start queue*).
- **Dragging a material** from the catalogue or *Mine* onto a part in the viewport or a row in the tree assigns it; `Alt` on drop gives it its own copy.
- **Box selection** with `Ctrl/⌘` + drag: window (left to right) or crossing (right to left), at *Model*, *Group*, *Part* or *Faces* level.
- **Whole CAD face.** At *Faces* level, one click picks the complete face in STEP and IGES, and *Separate by CAD faces* splits a part into one per face.
- **Glass, sky and HDRI.** Real glass (with colour by absorption and thin walls), a procedural *Sky*, environment from a `.hdr` or `.exr` file, and *Background image*.
- **AI post-processing, interface only.** The render window has the *AI post-processing* section and *Settings* installs the runtime (stable-diffusion.cpp), but it **does not generate any image yet**: the switch says *coming soon*.

The full list is in `docs/CHANGELOG.md`.

## Downloads

- **Repackshot-0.1.2-windows-x64-portable.zip**: Windows portable. Unzip it into a folder and run `repackshot.exe`. Settings, models and logs stay in the `data` folder next to the program.
- **Repackshot-0.1.2-windows-x64-setup.exe**: Windows installer. It installs for your user only (no administrator) into `%LOCALAPPDATA%\Programs\Repackshot`; data goes to `%LOCALAPPDATA%\Repackshot`.
- **Repackshot-0.1.2-linux-x64-portable.tar.gz**: Linux portable. Untar it and run `./repackshot`; it needs Chromium, Chrome, Edge or Brave.
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages.

To verify the downloads on Linux: `sha256sum -c SHA256SUMS.txt`. On Windows, in PowerShell: `Get-FileHash .\Repackshot-0.1.2-windows-x64-setup.exe -Algorithm SHA256` and compare with the line in the file.

## Requirements

- **Windows:** Windows 10 or 11, x64. The own window needs the Microsoft Edge WebView2 *runtime*, which Windows ships and keeps up to date; without it, an Edge or Chrome app window opens.
- **Linux:** x86_64, with Chromium, Google Chrome, Microsoft Edge or Brave. On Linux the window is still the browser's in app mode.

The `.exe` is not signed: SmartScreen may stop the first start. Click **More info** and then **Run anyway**.

## Known limitations

- **AI post-processing does not generate images yet.** The models and the runtime are downloaded and installed; the full pipeline is phase X3c.
- The Windows builds of the runtime need the **Visual C++ 2015–2022 (x64)** environment, which does not ship with Repackshot. If it is missing, *Settings* says so.
- The update check finds no versions while the repository is private.
- **The new desktop features have not been tested on a real Windows machine**: WebView2 window, closing, dialogs in front of the window, taskbar grouping, video memory, the installer, Vulkan with a real card and long Full-mode sessions. That is why this is a preview release.
- No video encoding (animations come out as frame sequences), STEP and IGES assume Z up, and there is no macOS version.

For testers: a manual Windows test plan is in [docs/testing/windows-checklist.md](https://github.com/Grohle-developer/Repackshot/blob/main/docs/testing/windows-checklist.md).
