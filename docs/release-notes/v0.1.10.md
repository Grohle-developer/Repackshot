# Repackshot 0.1.10

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release** with a feature the bug report of 2026-10-14 asked for: **image textures, their mapping and labels now show in *Full* mode and in renders**, not only in *Fast*.

## What's new

- **Textures in the engine.** The six slots of a material (colour, roughness, metal, normal, alpha and emission) with their image are painted in *Full* and in the render, in the same place as in *Fast*: the projection type (UV, box, planar, cylindrical, spherical), the size, the offset and the rotation you set in *Inspector ▸ Textures* move the texture in all three modes. Images are filtered by distance, with no flicker or jagged edges when moving away.
- **Normal and relief maps**, which add up with the edge bevel; **alpha** that really cuts out the part (also in shadows).
- **Labels** (*Add label…*) as a layer over the material, with their own finish and a paper edge; they show in their place in the render.
- The textures that imported models bring (glTF, OBJ+MTL, FBX, DAE, 3MF, USD, 3DM) now show in *Full* too.
- A scene without textures renders as before, pixel for pixel.

The full list, with its limitations, is in `docs/CHANGELOG.md`.

## Downloads

- **Repackshot-0.1.10-windows-x64-portable.zip**: Windows portable. Unzip it and run `repackshot.exe`. Data stays in the `data` folder next to the program.
- **Repackshot-0.1.10-windows-x64-setup.exe**: Windows installer, for your user only and without administrator. Data goes to `%LOCALAPPDATA%\Repackshot`.
- **Repackshot-0.1.10-linux-x64-portable.tar.gz**: Linux portable; it needs Chromium, Chrome, Edge or Brave (and glibc 2.38 or later for the AI).
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages. On Linux: `sha256sum -c SHA256SUMS.txt`; in PowerShell: `Get-FileHash .\Repackshot-0.1.10-windows-x64-setup.exe -Algorithm SHA256`.

The film simulation plugin does not change: it is still `film-0.1.0.rpk`, the asset of the 0.1.6 release.

The `.exe` is not signed: SmartScreen may stop the first start (**More info**, then **Run anyway**).

## Known limitations

- A texture’s size is still in millimetres: it does not yet fit itself to the size of the solid (how it coexists with the size you set by hand is still to be decided).
- **Node materials** still show as their average colour in *Full* until the next phase (M3b).
- A scene with textures takes about 16–19 % longer; an emitter with an image gives more noise in what it lights, and caustics do not see the textures.
- Those of 0.1.9 remain.

For testers: a manual Windows test plan is in [docs/testing/windows-checklist.md](https://github.com/Grohle-developer/Repackshot/blob/main/docs/testing/windows-checklist.md).
