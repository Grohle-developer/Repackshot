# Repackshot 0.1.8

Repackshot is a free, source-available 3D product renderer, in the style of KeyShot. It runs as a desktop app and in the browser, and it renders with its own engine, written in Rust with no dependencies.

**This is a preview release** with a single new feature, requested in the bug report of 2026-10-14: **the window with a lens’s elements** when the pointer rests on it.

## What's new

- **Lens window.** In *Camera ▸ Lens*, with *Traced lens*, let the pointer rest for a moment on a lens in the list (or reach it with the keyboard): a window opens beside it with its **cross-section** (the elements, the diaphragm and the image plane), its name, its source and the numbers the engine gives for it with your camera’s focal length, aperture and focus (focal length, aperture and T-stop, elements and groups, length). Over a character chip it shows the lenses of that character. While the engine answers it says so, and without the engine loaded it does not invent numbers.
- The lens list is now an own menu of the application (arrows, Enter and Esc), because the system dropdown does not let you know which entry the pointer is over.

The full list, with its limitations, is in `docs/CHANGELOG.md`.

## Downloads

- **Repackshot-0.1.8-windows-x64-portable.zip**: Windows portable. Unzip it and run `repackshot.exe`. Data stays in the `data` folder next to the program.
- **Repackshot-0.1.8-windows-x64-setup.exe**: Windows installer, for your user only and without administrator. Data goes to `%LOCALAPPDATA%\Repackshot`.
- **Repackshot-0.1.8-linux-x64-portable.tar.gz**: Linux portable; it needs Chromium, Chrome, Edge or Brave (and glibc 2.38 or later for the AI).
- **SHA256SUMS.txt**: the SHA-256 sums of the three packages. On Linux: `sha256sum -c SHA256SUMS.txt`; in PowerShell: `Get-FileHash .\Repackshot-0.1.8-windows-x64-setup.exe -Algorithm SHA256`.

The film simulation plugin does not change: it is still `film-0.1.0.rpk`, the asset of the 0.1.6 release.

The `.exe` is not signed: SmartScreen may stop the first start (**More info**, then **Run anyway**).

## Known limitations

- With a character of four lenses the window is about 550 px tall and is cut off on shorter screens. On the desktop it asks the launcher for the same service as the *Lens* section, but it has not been tested there.
- The lens list no longer searches when a letter is typed.
- Those of 0.1.7 remain (`docs/release-notes/v0.1.7.md`).

For testers: a manual Windows test plan is in [docs/testing/windows-checklist.md](https://github.com/Grohle-developer/Repackshot/blob/main/docs/testing/windows-checklist.md).
